# 协作中心

这是工作组的统一入口。任何成员接手任务时，按以下顺序拉取上下文：

1. AGENTS.md：协作规则和验证门禁。
2. docs/TEAM.md：角色、边界和决策责任。
3. docs/BACKLOG.md：优先级、任务状态、负责人和依赖。
4. WORKLOG.md：最近的全局工作摘要。
5. docs/progress/<module>.md：模块级详细进展、验证证据和交接。

## 记录层级

| 层级 | 文件 | 用途 | 更新时机 |
|---|---|---|---|
| 规则 | AGENTS.md | 统一工作方式 | 流程变更时 |
| 组织 | docs/TEAM.md | 角色和责任边界 | 组织调整时 |
| 计划 | docs/BACKLOG.md | 可执行任务和依赖 | 开始、阻塞、完成时 |
| 模块 | docs/progress/*.md | 详细进展和验证 | 每次有意义工作后 |
| 全局 | WORKLOG.md | 里程碑与跨模块摘要 | 每次任务状态变化后 |

## 信息同步原则

- 代码、配置和可重复验证结果优先于文档描述。
- 任务状态以 docs/BACKLOG.md 为准，细节以模块进度笔记为准。
- 如果文档与实现冲突，先标记冲突并建立修正任务，不得根据过时文档盲目改代码。
