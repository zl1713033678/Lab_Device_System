# ADR-0002：采用原生 HTML5 SVG 矢量蓝图替代 Leaflet 与静态位图

- **状态**：已采纳（Accepted）
- **日期**：2026-08-25
- **关联代码**：[`static/index.html`](../../static/index.html)

## 1. 背景与问题（Context）
早期界面依赖静态底图与 GIS 地图库叠加点位，存在图层受限于静态图片清晰度、离线局域网环境加载外部瓦片/依赖受阻、房间矩形槽位难以与建筑结构线及实时状态样式深度联动等问题。

## 2. 核心决策（Decision）
1. **零外部地图依赖**：完全剥离 Leaflet 等第三方 GIS 依赖，在 `static/index.html` 内直接使用原生 `<svg>` 绘制建筑外墙、承重柱、走廊、核心筒与实验室房间图元。
2. **视口与单状态源交互**：前端自研滚轮指针缩放与平移变换，并以统一 `selectedLaboratoryId` 驱动 SVG 图元、底部房间卡片与二级详情抽屉联动。

## 3. 后果与权衡（Consequences）
- **收益**：缩放无锯齿，纯内网/单机运行零 CDN 依赖，可直接在前端控制房间脉冲告警与热力着色。
- **代价与约束**：`static/index.html` 膨胀至 2800+ 行单文件应用，且当前 1F/2F/3F 房间映射与拖拽坐标在锁定态存在耦合缺陷（见 `BUG-006`），需按 `SPEC-003` 补齐楼层真实字段并逐步模块化拆分。
